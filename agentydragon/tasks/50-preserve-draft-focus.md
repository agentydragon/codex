# Task 50: Preserve draft focus during approval dialog

Make the approval dialog open in a way that allows cycling in and out of it without stealing focus from the prompt edit dialog. The input focus should remain in the draft editor by default so that typing continues in the draft and does not accidentally trigger approval actions.
