# TUI Styles Availability

List of style keys declared in `config.md` under `[tui.styles]`, grouped by whether they are currently recognized by the code (`core::config_types::Colors`) or not.

## Supported (exist)
- context-high
- context-medium
- context-low
- scroll-thumb-active
- scroll-thumb-inactive
- scroll-track
- popup-fg
- popup-bg
- exec-success
- exec-failure
- exec-timing
- diff-add
- diff-remove
- diff-modify
- diff-other
- approval-select-style
- approval-plain-style
- approval-error-style

## Unsupported (do not exist yet)
- composer-error-border
- history-border
- git-warning-border
- status-text
- tool-header
- tool-args
- history-approved
- history-denied
- history-pending
- history-session
- history-aborted
- history-rejected
- history-not-run
- history-error
- history-success
- history-failed
- history-unknown
- history-running
- history-na
- history-footer-bg
- dim-text
- reset
